# Survey Invite via QR Code (arena-mobile) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an already-logged-in Arena Mobile user scan a QR code shown on the Arena web admin's "Invite via QR code" dialog and join that survey, with a confirmation step (survey name, role, inviter) before the role is actually granted.

**Architecture:** Reuses the existing `QrScannerModal` component (`src/components/QrScannerModal`) exactly as `SettingsRemoteConnectionScreen` already does for the QR-login flow, but wires it into `SurveysListRemote` (the screen listing surveys available to the logged-in user in the cloud) instead of the logged-out connection screen — this feature is for an **already-authenticated** user, not a device pairing/login flow. Two new `SurveyService` functions call the two new server endpoints (`GET .../invite/qr/:token/preview`, `POST .../invite/qr/accept`) via the existing `RemoteService` HTTP client, which already attaches the current session's auth headers automatically — no new auth plumbing needed. A new `SurveyActions.acceptSurveyQrInvite` thunk chains preview → `ConfirmActions.show` (the existing app-wide confirm-dialog mechanism) → accept, then navigates back to `surveysListRemote`, whose existing `useNavigationFocus(loadSurveys)` hook already re-fetches the remote survey list on every focus — so the newly joined survey appears automatically, no new refresh action needed.

**Tech Stack:** TypeScript, React Native (Expo), Redux (thunks via `useAppDispatch`), `expo-camera`/`barcode-detector` (already used by `QrScannerModal`), Jest (`testEnvironment: "node"`, no `jest-expo` preset — native-backed modules must be mocked in tests).

## Global Constraints

- **Depends on the `arena` repo's plan being implemented and deployed first** (`survey-invite-via-qr-code-arena.md`): this plan assumes the server exposes `GET /api/survey/:surveyId/users/invite/qr/:token/preview` and `POST /api/survey/:surveyId/users/invite/qr/accept`.
- The QR payload is JSON `{ serverUrl, surveyId, token }` (matches the format `UserInviteQrDialog` in the `arena` repo's plan encodes). `serverUrl` here is **not** used to route the HTTP request (`RemoteService` always uses the app's own configured server, from `SettingsService.fetchSettings()`) — it must instead be checked against the app's current server and rejected with a clear error if they differ, since scanning a QR generated by a different Arena server than the one the app is connected to would otherwise silently fail (survey/token not found on the connected server).
- This feature is for a user who is **already logged in** — do not place it on `SettingsRemoteConnectionScreen` (that screen is for device pairing/login while logged out) or touch `RemoteConnectionActions`/`AuthService`.
- Any module reachable from `surveyService.ts` that touches native modules (`db`, `utils/Files`, anything under `service/repository`) must be mocked in unit tests — this repo's `jest.config.js` has no `jest-expo` preset, so native modules are not auto-mocked (see the existing precedent in `src/service/externalGps/ExternalGpsService.test.ts`).
- `npm run lint` is `eslint --fix --ext .js,.jsx .` — note it does not include `.ts`/`.tsx` by default; also run `yarn test:types` (`tsc`) to catch type errors, since ESLint alone won't.

```ts
const previewQrInvite = async ({
  surveyId,
  token,
}: {
  surveyId: number;
  token: string;
}): Promise<
  | { preview: { surveyName: string; groupName: string; invitedByName: string } }

      `api/survey/${surveyId}/users/invite/qr/${token}/preview`,

    return { preview };

  try {
    const { data } = await RemoteService.post(
      `api/survey/${surveyId}/users/invite/qr/accept`,
      { token },
    );
    const { survey } = data;
    return { survey };
  } catch (error) {

};
```

```ts
const acceptSurveyQrInvite =
  ({
    surveyId,
    token,
    navigation,
  }: {
    surveyId: number;
    token: string;
    navigation: any;
  }) =>
    async (dispatch: any) => {
      const previewResult = (await SurveyService.previewQrInvite({
        surveyId,
        token,
      })) as any;
      const { preview, errorKey: previewErrorKey } = previewResult;

      if (previewErrorKey || !preview) {
        dispatch(
          MessageActions.setMessage({
            content: "surveys:qrInvite.error",
            contentParams: { details: previewErrorKey ?? "invalid" },
          }),
        );
        return;
      }

      const { surveyName, groupName, invitedByName } = preview;

      dispatch(
        ConfirmActions.show({
          titleKey: "surveys:qrInvite.confirmTitle",
          messageKey: "surveys:qrInvite.confirmMessage",
          messageParams: { surveyName, groupName, invitedByName },
          confirmButtonTextKey: "surveys:qrInvite.join",
          onConfirm: async () => {
            const acceptResult = (await SurveyService.acceptQrInvite({
              surveyId,
              token,
            })) as any;

            if (acceptResult.errorKey) {
              dispatch(
                MessageActions.setMessage({
                  content: "surveys:qrInvite.error",
                  contentParams: { details: acceptResult.errorKey },
                }),
              );
              return;
            }

            dispatch(
              MessageActions.setMessage({
                content: "surveys:qrInvite.success",
                contentParams: { surveyName },
              }),
            );
            navigation.navigate(screenKeys.surveysListRemote as never);
          },
        }),
      );
    };
```

- [ ] **Step 2: Add the QR-parsing helper**

At module scope (top of the file, next to `minSurveysToShowSearchBar`), add:

```ts
const parseSurveyInviteQrData = (
  data: string,
): { serverUrl: string; surveyId: number; token: string } => {
  try {
    const parsedData = JSON.parse(data);
    const { serverUrl, surveyId, token } = parsedData;
    if (
      typeof serverUrl === "string" &&
      serverUrl.length > 0 &&
      (typeof surveyId === "number" || typeof surveyId === "string") &&
      typeof token === "string" &&
      token.length > 0
    ) {
      return { serverUrl, surveyId: Number(surveyId), token };
    }
  } catch {
    // ignore error
  }
  throw new Error("Invalid QR code data structure");
};
```

```ts
const onScanQrCode = useCallback(() => {
  setQrScannerVisible(true);
}, []);

const onQrScannerDismiss = useCallback(() => {
  setQrScannerVisible(false);
}, []);

const onQrScannerData = useCallback(
  async (data: string) => {
    setQrScannerVisible(false);
    try {
      const { serverUrl, surveyId, token } = parseSurveyInviteQrData(data);
      const settings = await SettingsService.fetchSettings();
      if (settings.serverUrl !== serverUrl) {
        dispatch(
          MessageActions.setMessage({ content: "surveys:qrInvite.wrongServer" }),
        );
        return;
      }
      dispatch(
        SurveyActions.acceptSurveyQrInvite({ surveyId, token, navigation }),
      );
    } catch {
      dispatch(
        MessageActions.setMessage({ content: "surveys:qrInvite.invalidQrCode" }),
      );
    }
  },
  [dispatch, navigation],
);
```
