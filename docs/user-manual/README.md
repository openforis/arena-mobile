# Arena Mobile user manual

- `arena-mobile-user-manual.docx`: the manual (English), edited with Word or LibreOffice Writer.
- `translations/<lang>.json`: translations of the manual (French, Spanish), paragraph by paragraph.
- `screenshots/<lang>/`: screenshots of the app, taken by the [User manual screenshots workflow](../../.github/workflows/user-manual-screenshots.yml).
- `screenshots.json`: images of the manual replaced with the screenshots.
- `scripts/`: build scripts.

The PDFs are generated by the [User manual workflow](../../.github/workflows/user-manual.yml) and are not committed:

- every published release gets them as assets and publishes them on GitHub Pages: the latest version opens in the browser at
  - English: <https://openforis.github.io/arena-mobile/arena-mobile-user-manual.pdf>
  - French: <https://openforis.github.io/arena-mobile/arena-mobile-user-manual-fr.pdf>
  - Spanish: <https://openforis.github.io/arena-mobile/arena-mobile-user-manual-es.pdf>
- every pull request changing the manual gets them as the `user-manual` artifact of the workflow run, to check the result.

## Updating the manual

Update the manual in the same pull request as every user-facing change.

- Keep the `{{version}}` and `{{releaseDate}}` placeholders on the cover: they are replaced with the version (from `package.json`) and the date when generating the PDF.
- The table of contents and the page numbers are updated when generating the PDF.
- Keep the document in `.docx` format (in LibreOffice: **Keep current format** when saving).
- The PDF is generated with LibreOffice: use fonts available on Linux or metric-compatible with them (e.g. Calibri, replaced by Carlito), and check the PDF artifact of the pull request.
- UI labels in bold, as they appear in the English version of the app (see `src/localization/en`).
- Crop the status bar out of phone screenshots.

## Translations

The French and Spanish manuals are generated from the English `.docx`: the text of every paragraph is replaced with its translation from `translations/<lang>.json` (a list of `source`/`target` pairs, where `source` is the English text of the paragraph), keeping the formatting, and the screenshots listed in `screenshots.json` are replaced with the ones taken in that language. Paragraphs without a translation are left in English (the build lists them).

In the texts, `<sN>…</sN>` wraps text with the same formatting (e.g. a bold UI label): keep the tags around the translated text (they can be moved or repeated); `<xN/>` is an image or a field: keep it. Use the UI labels of the app in that language (see `src/localization/<lang>`).

After changing the English manual, add the new or changed paragraphs to the translation files (with an empty `target`, to translate) and remove the ones no longer used:

```bash
python3 docs/user-manual/scripts/segments.py update docs/user-manual/arena-mobile-user-manual.docx docs/user-manual/translations/fr.json
```

## Screenshots

The [User manual screenshots workflow](../../.github/workflows/user-manual-screenshots.yml) runs the [Maestro flows](../../e2e/maestro/manual-screenshots) on an Android emulator with the demo survey, once for every language (English, French, Spanish), and commits the screenshots to `screenshots/<lang>`. It runs on pull requests changing the flows, or manually (**Run workflow**). When a flow fails, the screen at the failure is saved in `screenshots/_debug`.

To update the images of the English manual with the screenshots (all the images listed in `screenshots.json`):

```bash
python3 docs/user-manual/scripts/screenshots.py docs/user-manual/arena-mobile-user-manual.docx docs/user-manual/screenshots.json docs/user-manual/screenshots/en docs/user-manual/arena-mobile-user-manual.docx
```

## Generating the PDFs locally

```bash
yarn docs:manual
```

It requires [LibreOffice](https://www.libreoffice.org/), node and python3 with `lxml` and `Pillow`. If LibreOffice is not found, set the `SOFFICE` variable to the `soffice` executable. With a LibreOffice installed from the Linux distribution packages, `python3-uno` is also needed. To generate only some languages: `bash docs/user-manual/scripts/build.sh "en fr"`.
