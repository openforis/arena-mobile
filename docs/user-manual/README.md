# Arena Mobile user manual

- `arena-mobile-user-manual.md`: the manual (source, [pandoc Markdown](https://pandoc.org/MANUAL.html#pandocs-markdown)).
- `images/`: screenshots and logos used in the manual.
- `reference.docx`: styles, page setup, header and footer of the generated document.
- `scripts/`: build scripts.

The `.docx` and `.pdf` files are generated by the [User manual workflow](../../.github/workflows/user-manual.yml) and are not committed:

- every published release gets them as assets; the latest version is always at <https://github.com/openforis/arena-mobile/releases/latest/download/arena-mobile-user-manual.pdf> (and `.docx`);
- every pull request changing the manual gets them as the `user-manual` artifact of the workflow run, to check the result.

## Updating the manual

Update the manual in the same pull request as every user-facing change. The version (from `package.json`) and the date on the cover are filled in automatically.

To generate the documents locally:

```bash
yarn docs:manual
```

It requires [pandoc](https://pandoc.org/installing.html), [LibreOffice](https://www.libreoffice.org/) and node. If LibreOffice is not found, set the `SOFFICE` variable to the `soffice` executable. With a LibreOffice installed from the Linux distribution packages, `python3-uno` is also needed.

## Writing conventions

- Headings are numbered automatically: don't write numbers in them.
- Link to another section with its heading text, e.g. `[Auto-sync]`.
- Images: `![](images/name.jpg){width=30%}`; the width is relative to the page. Keep them at most ~4 inches tall (about 30% for full phone screenshots). Images alone in a paragraph are centered. Small icons inside a sentence: `{height=0.25in}`.
- Name images after their section (e.g. `send-data-2.jpg`). Crop the status bar out of phone screenshots.
- Notes: `> **Note:** ...`.
- UI labels in bold, as they appear in the English version of the app (see `src/localization/en`).

To change fonts, colors or the header/footer, edit the styles in `reference.docx` with Word or LibreOffice (its content is ignored).
